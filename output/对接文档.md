## 一、五分钟上手

```bash
cd D:/MV_DS/mv
"D:/Python311/python.exe" render.py stills 7.2          # 出一张静帧看效果
"D:/Python311/python.exe" render.py video test.mp4 130 140   # 出一段 10 秒的片段
```

`python` 要用 `D:\Python311\python.exe`。PATH 上默认的 `python` 是 3.13，没装依赖，直接跑会报 `ModuleNotFoundError`。下文为简洁仍写 `python`。

不要每次都渲染整片。调一个镜头时用 `stills` 出 2–3 帧，确认后再出短片段，最后才整片。

**渲染一帧发生的事**（`director/mv.py` 的 `MV.frame(t)`）：

1. 按时间 `t` 在 `self.shots` 里找到当前镜头
2. 若处于转场窗口，前后两个镜头分别渲染到 `a_fbo` / `b_fbo`，再经 `wipe.frag` 混合
3. 否则清空 `scene_fbo`，调用镜头函数 `fn(t, lt, d)`
4. 镜头函数返回一个 dict，覆盖 `POST_DEFAULT` 里的后处理参数
5. 两级模糊做泛光，`post.frag` 合成到 `out_fbo`

`lt` 是镜头内相对时间，`d` 是镜头时长。

## 三、常用绘制原语（`MV` 类方法）

| 方法 | 用途 |
| --- | --- |
| `bg(frag, blend=False, **u)` | 跑任意全屏着色器到当前画布 |
| `stage(**u)` | 舞台背景（幕布、灯泡、射灯、装饰线） |
| `stew(**u)` | 浓汤背景 |
| `comic(**u)` | 漫画网点背景 |
| `potatoes(pots, rim, key, exposure, glow, squash)` | 画一批 2D 土豆 |
| `fire(height, intensity, ...)` | 火焰层 |
| `img(tex, cx, cy, w, h, rot, uv, **fx)` | 贴一张图（带描边、阴影、色调等特效） |
| `l2d(who, x, y, height, motion, mphase, rot, sing, **pose)` | 画一个 Live2D 角色 |
| `text(s, x, y, size, font, fill, ...)` | 画文字 |
| `lyrics(t, **kw)` | 画当前歌词（逐字动画） |
| `parts(rows, additive=False)` | 画粒子 |
| `cast()` | 有序迭代角色行（尾巴 → 其他人 → 初音本体） |

坐标约定：x 向右、y 向**下**（屏幕像素），`H` 为 1080。

## 四、改一个镜头怎么做

### 换背景色调
改 `m.stage(uWall=(r, g, b), ...)`。舞台类和装饰类的取值参考现有镜头，深棕金是 `(.20, .09, .03)`。

### 加一句文字
```python
m.text('新文字', W / 2, H * .7, 40, font=m.at_serif, fill=(1, .9, .7), alpha=1.)
```
新字符必须出现在 `mv.py` 的 `EXTRA_TEXT` 里，否则图集里没有字形，会静默不画。

### 让角色排在别的角色后面
把原来的 `for j, who in enumerate(ROSTER)` 换成 `for j, who in m.cast()`。`cast()` 会自动先画一次 `miku_tail`。注意 `j` 的取值仍然是角色槽位（尾巴和多可得同一个 `j`），所以坐标计算不用改。如果循环体里有按角色触发的粒子爆发，记得排除 `miku_tail`，否则会重复触发。

### 发一批土豆
```python
pots = [((wx, wy, wz), radius, (axis_x, axis_y, axis_z), angle, seed, face)]
m.potatoes(pots, rim=(1, .6, .3), glow=.5)
```
`face=1` 是南瓜灯脸，`face=0` 是普通 kawaii 脸。`seed` 决定体型、眼睛、嘴型。

### 用现成的土豆发射器

前两个在 `director/common.py`，锅相关两个在 `director/shots.py`：

- `potato_fountain(t, t0, t1, rate, origin, ...)` — 从一点持续喷出
- `potato_rain(t, t0, t1, rate, ...)` — 全屏飘落
- `pot_floats(t, bowl, seed, n=9, n_front=0)` — 锅里的浮动土豆
- `cauldron(t, cx, cy, rx, ry, glaze, stew, layer)` — 锅体，`layer` 决定前后壁

## 五、着色器改动

### 加一个 uniform
三处都要改：

1. 着色器里声明 `uniform float uFoo;`
2. `MV` 里的绘制方法给默认值（例如 `stage()` 的字典）
3. 镜头函数里按需覆盖

后处理参数统一在三处：

1. `shaders/post.frag` 声明
2. `director/mv.py` 的 `POST_DEFAULT` 给默认值
3. 镜头函数的返回 dict 覆盖

**漏掉第 2 步会直接崩溃**，因为 `pass_` 会把 dict 里所有键当 uniform 传。

### 复用 `common.glsl`
所有着色器都能用 `#include "common.glsl"`，里面有 hash、noise、fbm、voronoi、SDF 形状、`rot2`、`luma`、`halftone`。

## 六、坑

**1. 透明与混合**
`bg()` 默认不开混合，背景类 shader 直接覆盖画布。要在已画好的内容上叠透明层，必须传 `blend=True`。结尾幕布曾经因为漏传，把画好的土豆整块擦成透明。

**2. 绘制次序就是图层**
没有深度缓冲，后画的压住先画的。锅分三层（`layer=2` 后壁 → 角色 → `layer=0` 汤面 → `layer=1` 前壁），顺序错了就是"锅里没人"或者"人浮在锅外面"。

**3. 土豆的旋转轴**
`uRot` 是轴角。z 轴分量导致画面内自转，转多了脸会倒过来。要左右摇，用 `(0, 1, .2)` 这类以 y 轴为主的轴配小幅角度。

**4. Live2D 的 GL 状态**
`Character.render()` 前后会重置 VAO / program 绑定。如果你在别的渲染 pass 里改了这些状态，调完 `l2d()` 后要重新绑。

**5. 字形必须预注册**
`EXTRA_TEXT` 是字形白名单。加新字符忘了加进去，文字会静默消失，不报错。本轮就踩过：奥付页的「集」「価」「検印」全部没画出来，页面看起来像排版失误，其实是字集缺失。改了 `EXTRA_TEXT` 后图集会整张重建（首次约一分钟），之后走 `work/cache`。

**6. 长镜头会变幻灯片**
成片里一页停 8 秒以上就必须有内部运动，否则再好的排版也会被看成静态图。现在靠三样东西撑着：`add(..., cam=True)` 的缓慢推近、`typo.display` 里的节拍微缩放、以及逐字歌词的扫色。新写长镜头时记得至少留一个。

**7. 渲染速度**
现在约 190–200 帧/秒（1080p60），整片约 60 秒，比 Live2D 时代快一倍。改完着色器仍要先出静帧，着色器编译失败只在第一帧暴露。

**8. 编码器**
`render.py` 写死了 `h264_nvenc`。换机器没有 NVIDIA 卡的话，改成 `libx264` 并把 `-rc vbr -cq` 换成 `-crf`。

## 七、验证流程

改完之后至少做这三步：

```bash
python render.py stills <改动的时间点> <前后各一帧>
python render.py video seg.mp4 <t0> <t1>     # 看动态衔接
python render.py video D:/MV_DS/output/potato_MV.mp4   # 整片
```

静帧看构图和图层，短片看动效和转场衔接，整片看全局一致性（尤其是色调改动）。

从成片本身抽帧核对（而不是看中间渲染结果）：

```bash
FF=$(python -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
"$FF" -y -ss 157.5 -i D:/MV_DS/output/potato_MV.mp4 -frames:v 1 check.png
```
